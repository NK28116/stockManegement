# System Description

The codebase is structured into several directories and modules that work together to provide a comprehensive stock management and analysis system. Here is a detailed overview of the system's components:

## Data Management

The `data` directory contains various data files used by the system, including:

- `my_stock.csv`: A list of stocks that are currently held by the user.
- `quarterly_analysis.csv`: A file that stores quarterly analysis results.
- `report/summary/`: A directory that contains summary reports of analysis results.
- `report/detail/`: A directory that contains detailed reports of analysis results.
- `chartImg/`: A directory that stores stock charts.

The `python/analysis/data_collector` module is responsible for collecting data from various sources, such as stock prices, financial statements, and news articles.

## Configuration

The [python/config.py](cci:7://file:///Users/niwa_kazuhiro/Documents/PrivateDevelop/stockManegement/python/config.py:0:0-0:0) file contains configuration settings for the system, including:

- Environment variables and their default values.
- Database connection settings.
- Alert settings, such as the Slack webhook URL.

## Trading

The [python/trading](cci:7://file:///Users/niwa_kazuhiro/Documents/PrivateDevelop/stockManegement/python/trading:0:0-0:0) directory contains modules related to trading, including:

- `trading_rules.py`: Defines trading rules based on technical indicators and risk management strategies.
- `every_stock_BuySell_timing.py`: Analyzes stock data and suggests buy/sell timing for each stock in the portfolio.
- `buy_and_sell_stock.py`: Manages the buying and selling of stocks based on code.csv.

## Watch

The [python/watch](cci:7://file:///Users/niwa_kazuhiro/Documents/PrivateDevelop/stockManegement/python/watch:0:0-0:0) directory contains modules related to real-time monitoring, including:

- `watch.py`: Collects real-time stock data and performs real-time analysis.
- `analyze.py`: Analyzes the monitoring results and triggers alerts based on abnormal behavior.
- `dailyAggregator.py`: Aggregates daily stock data.

## Visualization

The [python/visualization](cci:7://file:///Users/niwa_kazuhiro/Documents/PrivateDevelop/stockManegement/python/visualization:0:0-0:0) directory contains modules related to visualization, including:

- `stock_chart_visualizer.py`: Creates stock charts based on technical indicators.
- `view_charts.py`: Displays the created stock charts.
- `generate_all_charts.py`: Generates all stock charts at once.

## Utilities

The [python/utils](cci:7://file:///Users/niwa_kazuhiro/Documents/PrivateDevelop/stockManegement/python/utils:0:0-0:0) directory contains utility modules, including:

- `alert.py`: Provides alert functionality for stock price changes, buy/sell signals, and risk management.
- `indicator.py`: Calculates technical indicators.

## Database

The [python/db](cci:7://file:///Users/niwa_kazuhiro/Documents/PrivateDevelop/stockManegement/python/db:0:0-0:0) directory contains the database module, including:

- `stock.db`: The SQLite database for storing stock data.
- `init_database.py`: Initializes the database.

## Makefile

The `makefile` provides convenient commands for running various tasks, such as running the entire system, analyzing stock data, creating stock charts, and more.

## Logs

The `logs` directory stores log files generated by the system.

This system provides a comprehensive solution for managing and analyzing stock data, including real-time monitoring, buy/sell timing analysis, portfolio analysis, and visualization. It utilizes various data sources, technical indicators, and risk management strategies to provide valuable insights for stock traders and investors.
