# `data` ディレクトリ

このディレクトリには、株管理システムが使用する様々なデータファイル、および生成されたレポートやチャートが保存されます。

## ファイル一覧/サブディレクトリ

- `my_stock.sample.csv`:
  ポートフォリオ CSV の形式を示す架空のサンプルです。ローカルでは `my_stock_local.csv` にコピーして使います。
  実際の保有データ (`my_stock*.csv`)、生成したチャート画像 (`chartImg/`, `plots/`)、
  `latest_indicators.json` は個人の取引内容が分かるため、リポジトリに含めません (`.gitignore` 対象)。

- `quarterly_analysis.csv`:
  四半期ごとの分析結果を保存するCSVファイルです。

- `analyze_my_stock/`:
  個別の銘柄分析に関連するデータや設定を保存するディレクトリです。

- `API/`:
  API連携に関するローカル設定を置くディレクトリです。認証情報や証券会社の API 仕様書はリポジトリに含めません (`.gitignore` 対象)。

- `archive/`:
  過去のデータや古いレポートなどをアーカイブとして保存するディレクトリです。

- `chartImg/`:
  生成された株価チャートの画像ファイルを保存するディレクトリです。

- `plots/`:
  テクニカル指標などのプロット画像を保存するディレクトリです。

- `practice/`:
  練習用のポートフォリオデータや分析結果を保存するディレクトリです。

- `report/`:
  詳細レポートやサマリーレポートなどの分析結果を保存するディレクトリです。
