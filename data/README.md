# ポートフォリオ管理データ
所持資産のポートフォリオデータを集約しているディレクトリ

## 機能
- **ポートフォリオ管理**: 所持している株式の一覧とステータス管理
- **チャート画像**: 所持している株式の価格チャート画像
- **価格監視レポート**:売買タイミングを分析するレポート
- **ポートフォリオレポート**: 所持資産の損益状況を分析するレポート


## 構成

```
data/
├── my_stock.csv            # ポートフォリオ管理ファイル
├── chartImg/           # 生成されたチャート画像
│   ├── 7203_T_トヨタ自動車.png
│   ├── 6758_T_ソニーグループ.png
│   └── ...
├── reports/            # 生成されたレポートファイル
│   ├── detail/
｜          ├── detail_report_YYYYMMDD_HHMMSS.txt  # 各銘柄の詳細レポート
│          └── ...
│   ├── summary/
｜          ├── summary_report_YYYYMMDD_HHMMSS.txt  # 各銘柄の簡易レポート
│          └── ...
└── my_portfolio_analysis.txt  # 売買タイミング分析レポート
```

## **列の説明**

| 列名 | 説明 | 例 |
|------|------|-----|
| **status** | 売却ステータス | `保有中`, `売却済`, `部分売却` ,`監視中`|
| **current_price** | 現在価格 | 最新の株価（自動更新） |
| **profit_loss** | 損益額 | 現在価格 - 購入価格 × 数量 |
| **profit_loss_percent** | 損益率 | 損益額 ÷ 投資額 × 100 |
| **last_updated** | 最終更新日 | データの更新日時 |

## **売却ステータスの種類**

### **保有中**
- 現在も保有している株式
- 分析対象として扱う

### **売却済**
- 全数量を売却済みの株式
- 過去の取引履歴として記録

### **部分売却**
- 一部数量を売却した株式
- 残り数量で継続保有

### **監視中**
- まだ購入していないが、購入を検討している株式
- 将来の購入計画として記録 
- どのように値動きを見守るかの参考にする
