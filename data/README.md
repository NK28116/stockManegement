
## **列の説明**

| 列名 | 説明 | 例 |
|------|------|-----|
| **status** | 売却ステータス | `保有中`, `売却済`, `部分売却` ,`購入予定`|
| **current_price** | 現在価格 | 最新の株価（自動更新） |
| **profit_loss** | 損益額 | 現在価格 - 購入価格 × 数量 |
| **profit_loss_percent** | 損益率 | 損益額 ÷ 投資額 × 100 |
| **last_updated** | 最終更新日 | データの更新日時 |

## **売却ステータスの種類**

### **保有中**
- 現在も保有している株式
- 分析対象として扱う

### **売却済**
- 全数量を売却済みの株式
- 過去の取引履歴として記録

### **部分売却**
- 一部数量を売却した株式
- 残り数量で継続保有

### **購入予定**
- まだ購入していないが、購入を検討している株式
- 将来の購入計画として記録 
- どのように値動きを見守るかの参考にする

## **使用方法の例**

### **1. 保有株式の確認**
```bash
# 現在保有中の株式のみ表示
python3 every_stock_BuySell_timing.py ../data/codes.csv --status 保有中
```

### **2. 損益状況の確認**
```bash
# 損益率でソートして表示
python3 portfolio_analyzer.py --sort-by profit_loss_percent
```

### **3. 売却済み株式の履歴**
```bash
# 売却済み株式の分析
python3 portfolio_analyzer.py --include-sold
```

## **自動更新の仕組み**

`every_stock_BuySell_timing.py`を実行すると、以下の情報が自動更新されます：

1. **現在価格**: Yahoo Financeから最新株価を取得
2. **損益計算**: 購入価格との差額を計算
3. **更新日時**: 最終更新日時を記録

## **ポートフォリオ分析での活用**

### **保有資産の可視化**
- 現在の資産価値
- 各銘柄の損益状況
- 業種別の分散状況

### **売買タイミングの最適化**
- 利益確定のタイミング
- 損失切り止めの判断
- ポートフォリオの再構築
