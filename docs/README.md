# 所持資産運用診断ツール

## 概要
収支をGASとpythonで分析したい

### フロー
スプレッドシート
- シート「資産」
  - [銘柄,取引所,証券コード,株価,口数,購入額]
- シート「評価」
  - [銘柄,評価]列
  - [所持資産，売却資産]
- シート「収支」
  - [初期資産,今月資産,先月資産]

1. stockManegement.py
   1. buy 
      1. 銘柄名と口数を入力
      2. シート「資産」に[銘柄,取引所,証券コード,株価,口数,購入額]の列の一番下に追加
      3. シート「評価」の[所持資産]行の[銘柄,評価]の列に追加
      4. シート「収支」の「今月資産」から購入額を引く
   2. sell
      1. 銘柄名と口数を入力
      2. シート「資産」から該当の銘柄を削除
      3. シート「評価」の「売却資産」の[銘柄,評価]の列に追加
      4. シート「収支」の「今月資産」に売却額を加える
   3. watch
      1. 分足で監視して暴落に備える
      2. 日足で監視して売買ルールに基づいた評価をする
   4. analyse(1週間ごとに自動で実行)
      1. 1週間ごとに分析する
      2. その週での収支を分析する
         1. 移動平均線
         2. 騰落レシオ
         3. RSI

### 2. **ポートフォリオの見方**

#### **重要指標の読み方**

| 指標 | 良い値 | 悪い値 | 意味 |
|------|--------|--------|------|
| **総リターン** | +5%以上 | -5%以下 | 期間中の収益率 |
| **年率リターン** | +10%以上 | -10%以下 | 年間換算の収益率 |
| **ボラティリティ** | 20%以下 | 40%以上 | 価格変動の激しさ |
| **シャープレシオ** | 1.0以上 | 0.5以下 | リスク調整後リターン |
| **最大ドローダウン** | -10%以内 | -20%以下 | 最大の損失幅 |
| **勝率** | 60%以上 | 40%以下 | 利益が出る取引の割合 |

#### **分散効果の見方**

```
平均相関係数:
- 0.3未満 → ✅ 良好な分散効果
- 0.3-0.6 → ⚠️ 中程度の分散効果  
- 0.6以上 → ❌ 分散効果が限定的
```

## 🎓 **学習のポイント**

### **1. リスク管理の重要性**
- 最大ドローダウンが-20%を超えない
- ボラティリティは30%以下を目指す
- ストップロスを必ず設定

### **2. 分散投資の効果**
- 異なるセクターに投資
- 相関係数を0.6以下に抑える
- 5-10銘柄程度に分散

### **3. 感情に左右されない取引**
- 明確なルールに従う
- 損切りを躊躇しない
- 利益確定も機械的に
