# 所持資産運用診断ツール

## 概要
収支をGASとpythonで分析したい

### フロー
スプレッドシート
- シート「資産」
  - [銘柄,取引所,証券コード,株価,口数,購入額]
- シート「評価」
  - [銘柄,評価]列
  - [所持資産，売却資産]
- シート「収支」
  - [初期資産,今月資産,先月資産]

1. stockManegement.py
   1. buy 
      1. 銘柄名と口数を入力
      2. シート「資産」に[銘柄,取引所,証券コード,株価,口数,購入額]の列の一番下に追加
      3. シート「評価」の[所持資産]行の[銘柄,評価]の列に追加
      4. シート「収支」の「今月資産」から購入額を引く
   2. sell
      1. 銘柄名と口数を入力
      2. シート「資産」から該当の銘柄を削除
      3. シート「評価」の「売却資産」の[銘柄,評価]の列に追加
      4. シート「収支」の「今月資産」に売却額を加える
   3. watch
      1. 分足で監視して暴落に備える
      2. 日足で監視して売買ルールに基づいた評価をする
   4. analyse(1週間ごとに自動で実行)
      1. 1週間ごとに分析する
      2. その週での収支を分析する
         1. 移動平均線
         2. 騰落レシオ
         3. RSI
