# 株価チャート可視化ツール

このツールセットは、ポートフォリオ内の全銘柄について売買タイミングを可視化するためのツールです。

## 機能

- **自動売買シグナル検出**: ゴールデンクロス（++）とデッドクロス（--）パターンの検出
- **リスク管理**: ストップロス（5%）、利確（10%）、トレーリングストップ（3%）
- **視覚的チャート**: 価格チャート、出来高、移動平均線、売買ポイントの表示
- **詳細レポート**: 各銘柄の取引パフォーマンス分析

## ファイル構成

```
python/
├── stock_chart_visualizer.py      # メイン可視化クラス
├── generate_all_charts.py         # 全銘柄一括処理
├── single_stock_demo.py           # 単一銘柄デモ
├── view_charts.py                 # チャート表示ヘルパー
├── trading_rules.py               # 売買ルールエンジン
└── README_CHARTS.md              # このファイル
```

## 使用方法

### 1. 全銘柄のチャート作成

```bash
# ポートフォリオ内の全銘柄を一括処理
python3 generate_all_charts.py
```

これにより以下が生成されます：
- 各銘柄のチャート画像（PNG形式）
- 取引サマリーレポート（TXT形式）

### 2. インタラクティブ選択

```bash
# ポートフォリオと期間を選択
python3 stock_chart_visualizer.py
```

利用可能なオプション：
- ポートフォリオ: practice, beginner, diversified, growth, stable
- 期間: 1mo, 3mo, 6mo, 1y

### 3. 単一銘柄のデモ

```bash
# トヨタ自動車のデモチャート
python3 single_stock_demo.py
```

### 4. チャート表示

```bash
# Finderでチャートフォルダを開く
python3 view_charts.py

# サマリーレポートを表示
python3 view_charts.py --summary
```

## 出力内容

### チャート要素

1. **価格チャート**（上部）
   - 終値ライン（青）
   - 5日移動平均線（オレンジ）
   - 25日移動平均線（紫）
   - 買いシグナル（緑の上向き三角）
   - 売りシグナル（赤の下向き三角）

2. **出来高チャート**（下部）
   - 日次出来高（グレーのバー）

3. **アノテーション**
   - 各売買ポイントに価格と損益率を表示
   - 売買理由（ゴールデンクロス、デッドクロス、ストップロス等）

### サマリーレポート内容

各銘柄について以下の情報を提供：

## 売買ルール詳細

### エントリー条件
- **ゴールデンクロス（++）**: 2日連続の価格上昇

### エグジット条件
1. **デッドクロス（--）**: 2日連続の価格下落
2. **利確**: +10%到達時
3. **ストップロス**: -5%到達時
4. **トレーリングストップ**: 最高値から3%下落

### パフォーマンス指標
- **勝率**: 利益を出した取引の割合
- **平均損益**: 取引当たりの平均利益率
- **総リターン**: 全取引の累積リターン
- **プロフィットファクター**: 総利益 ÷ 総損失

## 技術的詳細

### 依存関係
- `yfinance`: 株価データ取得
- `matplotlib`: チャート作成
- `pandas`: データ処理
- `numpy`: 数値計算

### データソース
- Yahoo Finance API（yfinance経由）
- リアルタイム日本株データ

### ファイル形式
- チャート: PNG（150 DPI）
- レポート: UTF-8テキスト
- 設定: CSV形式のポートフォリオ

## カスタマイズ

### パラメータ調整
`trading_rules.py`で以下を変更可能：
```python
ImprovedTradingRules(
    stop_loss_percent=0.05,    # ストップロス（5%）
    take_profit_percent=0.10,  # 利確（10%）
    trailing_stop_percent=0.03 # トレーリングストップ（3%）
)
```

### 新しいポートフォリオ追加
1. `data/`フォルダに新しいCSVファイルを作成
2. `stock_chart_visualizer.py`の`portfolios`リストに追加

### チャートスタイル変更
`create_chart_with_signals()`メソッドで色、サイズ、レイアウトを調整可能

## トラブルシューティング

### データ取得エラー
- インターネット接続を確認
- ティッカーシンボルの正確性を確認
- Yahoo Financeのサービス状況を確認

### フォント警告
- システムフォントが見つからない場合の警告（機能には影響なし）
- macOSの場合、通常は`DejaVu Sans`が使用される

### メモリ使用量
- 大量銘柄処理時はメモリ使用量に注意
- 必要に応じて分割処理を検討
