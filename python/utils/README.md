# `utils` ディレクトリ

このディレクトリには、様々なユーティリティ関数やクラスが含まれています。これらは、株管理システム全体の異なる部分で再利用可能な共通の機能を提供します。

## ファイル一覧

- `alert.py`:
  株価の変動や特定のイベントが発生した際に、ユーザーに通知するためのアラート機能を実装しています。

- `indicators.py`:
  テクニカル指標（例: 移動平均、RSI、MACDなど）を計算するための関数を提供します。これらの指標は、株価分析や取引戦略の決定に利用されます。

- `logger.py`:
  アプリケーションのログ記録を管理するためのモジュールです。システムの状態、エラー、重要なイベントなどを記録し、デバッグや監視に役立てます。

- `monitor.py`:
  市場データやポートフォリオの状況を監視するための機能を提供します。特定の条件が満たされた場合に、アラートを発したり、データを更新したりします。

- `report.py`:
  分析結果や取引履歴などのレポートを生成するための機能を提供します。これにより、ユーザーは自身の投資状況を視覚的に把握できます。
