# `watch` ディレクトリ

このディレクトリには、市場の監視と日次データ集計に関連するモジュールが含まれています。株価データや市場の動向を継続的に追跡し、分析のためのデータを準備します。

## ファイル一覧

- `analyze.py`:
  監視対象の株価データや市場データを分析し、特定のパターンやトレンドを検出するための機能を提供します。

- `dailyAggregator.py`:
  日次の株価データや取引データを集計し、データベースやファイルに保存するための機能を提供します。

- `watch.py`:
  市場全体の監視プロセスを管理します。定期的にデータを取得し、他のモジュールに処理を渡します。
