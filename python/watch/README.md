# リアルタイム監視

暴落に備えたリアルタイム監視ツールです．基本的に，1分毎に株価をチェックし，5%以上の暴落があればアラートを出します．

## 機能

- **リアルタイム監視**: 1分毎に株価をチェックし，5%以上の暴落を検出
- **アラート通知**: 暴落検出時にコンソールにアラートを表示  

## 構成

```
watch/
|── watch.py                    # メイン監視クラス
|── analyze.py                  # 株価データを分析する
|── dailyAggregator.py          # 分足データを日足データに集計する
```

### 概要

1.  **`watch.py` (リアルタイムデータ取得と一次検知)**
    *   **役割**: 指定された間隔（例: 2分ごと）で、監視対象の銘柄の株価（終値、出来高など）をリアルタイムまたは擬似リアルタイムで取得し、データベース（`intraday` テーブル）に保存します。
    *   **機能**:
        *   `yfinance` や将来的な証券会社API/WebSocketからのデータ取得ロジック。
        *   取得したデータをSQLiteデータベースの分足データテーブルに格納。
        *   ごく基本的な一次検知（例: 前回比-3%以上の急落）を行い、ログ出力または `alert.py` を呼び出す。
        *   開発モード（過去データでのシミュレーション）と本番モードの切り替え機能。

2.  **`dailyAggregator.py` (分足データの日足集計)**
    *   **役割**: `watch.py` が収集した分足データ（`intraday` テーブル）を基に、日足データ（始値、高値、安値、終値、出来高）を集計し、別のデータベーステーブル（例: `daily_prices`）に保存します。
    *   **機能**:
        *   指定された期間（例: 1日）の分足データを読み込む。
        *   OHLCV（始値、高値、安値、終値、出来高）を計算するロジック。
        *   集計した日足データをデータベースに格納。
        *   日次で自動実行されるような設計（例: cronジョブやスケジューラから呼び出される）。

3.  **`analyze.py` (リアルタイム分析と高度な急落・乱高下検知)**
    *   **役割**: `watch.py` が取得した分足データや `dailyAggregator.py` が集計した日足データを利用して、より高度なリアルタイム分析を行い、異常な動きを検知してアラートを発します。
    *   **機能**:
        *   **急落検知**:
            *   「数分で-3%」のような短期間での急落を検知。
            *   ダマシ回避ロジック（例: 連続2本で同方向確認、一時的な反発を考慮）。
        *   **乱高下検知 (ボラティリティ監視)**:
            *   直近N本（例: 30分間）の分足データで標準偏差（σ）を計算し、通常より大きなボラティリティを検知。
            *   ボラティリティフィルタ（例: ATRや標準偏差を使って、その日の変動が大きすぎるときは見送り）。
        *   **アラート連携**:
            *   検知した急落や乱高下に対して、`utils/alert.py` の `send_alert` 関数を呼び出し、SlackやLINEなどの外部サービスに通知を送信。
            *   通知のフィルタリング（例: 一定期間内の重複通知抑制、重要度に応じた通知レベル）。
        *   **拡張性**: 将来的にRSIやボリンジャーバンドなどの短期指標をリアルタイム分析に組み込むための基盤。

これらのコードが連携することで、リアルタイムでの株価監視、異常値の検知、そして適切なアラート通知が可能になります。
