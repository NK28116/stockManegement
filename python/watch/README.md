# リアルタイム監視
暴落に備えたリアルタイム監視ツールです．基本的に，1分毎に株価をチェックし，5%以上の暴落があればアラートを出します．

## 機能
- **リアルタイム監視**: 1分毎に株価をチェックし，5%以上の暴落を検出
- **アラート通知**: 暴落検出時にコンソールにアラートを表示  

## 構成

```
watch/
|── watch.py                    # メイン監視クラス
|── analyze.py                  # 株価データを分析する
|── dailyAggregator.py          # 分足データを日足データに集計する
```
