# Stock Watch & Analysis System

このディレクトリは、株価データの収集・保存・分析を行うミニシステムです。  
証券会社APIまたはランダム生成値を利用し、**分足データの収集 → 日足集計 → テクニカル分析**までを一貫して処理できます。

---

## 構成ファイル

### 1. `watch.py`

- **役割**: リアルタイムまたは開発モードで株価データを取得し、DBに保存する
- **モード**
  - `--dev YYYYMMDD` : 過去日の擬似リアルタイム監視
  - 引数なし : 本番モードで2分ごとに株価を取得
- **主な機能**
  - APIキー未設定時はランダム値を使用（ログ出力あり）
  - APIキー設定時は証券会社APIを利用
  - 連続下落検知
  - ボラティリティ警告
  - 急落検知（前回比3%以上など）

---

### 2. `dailyAggregator.py`

- **役割**: intraday（分足）データを集計し、日足データを生成
- **処理内容**
  - 指定日の分足データから `open/high/low/close/volume` を算出
  - `daily` テーブルに保存

### 3. `analyze.py`

- **役割**: 日足データを分析し、テクニカル指標や急落検知を実施
  - 主な機能
    - 前日比急落検知（閾値は config.crash_threshold）
    - MACD:
    - ゴールデンクロス / デッドクロス判定
    - ボリンジャーバンド:
    - アッパーバンド/ローワーバンドのブレイクアウト検知
