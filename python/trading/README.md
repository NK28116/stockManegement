# 所持運用資産の操作
所持している株などの運用資産を実際に運用する際に使うツール

## 機能

- **所持資産の管理**: 株式の購入・売却・監視銘柄の管理
- **所持資産の売買**: 株式の売買タイミングの分析

## ディレクトリ構成

```
trading/
├── every_stock_BuySell_timing.py  # 保有株式の売買タイミング分析
├── buy_and_sell_stock.py          # 保有株式の管理
├── trading_rules.py               # 売買タイミングの判断基準
```

## 使用方法

### 1.保有株式の管理

```bash
python3 buy_and_sell_stock.py buy 7203.T 1000  # トヨタ自動車を1000株購入
```
これにより,`data/my_stock.csv`に保有株式として追加します

```bash
python3 buy_and_sell_stock.py sell 7203.T 500   # トヨタ自動車を500株売却
```
これにより,`data/my_stock.csv`から売却株式としてステータスを更新します

```bash
python3 buy_and_sell_stock.py prebuy 7203.T 1000          # 保有株式の一覧表示
```
これにより,`data/my_stock.csv`に監視株式として追加されます

### 2.売買処理を行うタイミングを分析

```bash
python3 every_stock_BuySell_timing.py ../data/my_stock.csv 
```
これにより,保有株式の売買タイミングを分析します

### 3.売買タイミングの判断基準
売買タイミングの判断基準は`trading_rules.py`
具体的な基準は以下の数字を利用しています

```python
    def __init__(self, 
                stop_loss_percent: float = 0.05,  # 5%ストップロス
                take_profit_percent: float = 0.10,  # 10%利確
                trailing_stop_percent: float = 0.03):  # 3%トレーリングストップ
        self.stop_loss_percent = stop_loss_percent
        self.take_profit_percent = take_profit_percent
        self.trailing_stop_percent = trailing_stop_percent
```

## 売買ルール詳細

### エントリー条件
- **ゴールデンクロス（++）**: 2日連続の価格上昇

### エグジット条件
1. **デッドクロス（--）**: 2日連続の価格下落
2. **利確**: +10%到達時
3. **ストップロス**: -5%到達時
4. **トレーリングストップ**: 最高値から3%下落

### パフォーマンス指標
- **勝率**: 利益を出した取引の割合
- **平均損益**: 取引当たりの平均利益率
- **総リターン**: 全取引の累積リターン
- **プロフィットファクター**: 総利益 ÷ 総損失
