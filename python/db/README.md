# `db` ディレクトリ

このディレクトリには、データベースの操作に関連するモジュールが含まれています。株管理システムが利用するデータの永続化、取得、管理を行います。

## ファイル一覧

- `database.py`:
  PostgreSQLデータベースへの接続を確立するための関数を提供します。

- `init_database.py`:
  データベースの初期化スクリプトです。テーブルの作成、既存カラムのリネーム（`sector`から`purpose`へ）、`transactions`テーブルの追加など、データベーススキーマの管理を行います。既存のデータは保持されます。

- `dump_csv.py`:
  データベースからデータをCSVファイルにエクスポートするための機能を提供します。これにより、データのバックアップや他のツールでの分析が可能になります。

## データベースの初期化と更新

システムを初めてセットアップする場合や、データベーススキーマの変更を適用する際には、`init_database.py`スクリプトを実行する必要があります。

```bash
python3 -m python.init_database
```

このコマンドを実行することで、以下の操作が行われます。

*   必要なテーブルがまだ存在しない場合は作成されます。
*   既存の`stocks`、`portfolio`、`pre_buy_daily`テーブルに`sector`カラムが存在する場合、`purpose`カラムにリネームされます。既存のデータは保持されます。
*   `transactions`テーブルが作成されます。

これにより、データベースが最新のスキーマに更新され、システムが正しく動作するための準備が整います。
